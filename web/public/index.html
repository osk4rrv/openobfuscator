How it works

Source in.
Loader out.

The server runs the project’s C++ binary, encodes the source into randomized data, and returns a language-specific loader. This is source obfuscation, not encryption or bytecode.

Read the source
01

Transform

Lua presets can rename locals, rewrite literals, add junk statements, and add optional guards.

02

Encode

The source is stored as randomized numeric data and reconstructed by a generated JavaScript or Lua loader.

03

Verify

The loader checks its data length, termination marker, and Adler-32 checksum before running the source.

JavaScript source-VM output targets CommonJS and classic scripts that do not depend on persistent top-level lexical bindings. ECMAScript modules are not supported. Lua source-VM output requires LuaJIT and its bit API.

The actual V1.2 engine

Not a lookalike.
The native core.

The website calls the same C++ implementation distributed by the GitHub project. Each request runs the native CLI as a short-lived process under a dedicated, restricted VPS account; the application does not intentionally persist submitted source or generated output.

01

Randomized instruction set

Every run assigns new opcodes for byte emission, key mutation, noise, and HALT.

02

Integrity before execution

The runtime checks HALT flow, reconstructed byte length, and Adler-32 before loading source.

03

Language-specific runtime

The shared instruction stream emits a LuaJIT loader or a modern JavaScript wrapper.

Open by default

Inspect every layer.

OpenObfuscator is MIT-licensed, has no account system, and adds no watermark. Obfuscation increases reverse-engineering cost; it does not turn client-side secrets into safe data.
